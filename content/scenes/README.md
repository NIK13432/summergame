# Свои сцены

Положи сюда любой `*.json` — сервер подхватит его при запуске.

```json
{
  "chapters": [ { "id": "ch6", "title": "Глава 6", "cost": 30000, "premium": true, "nodes": [ ... ] } ],
  "moments":  [ { "id": "m_lisa_2", "char": "lisa", "title": "...", "minAffection": 20, "premium": true, "nodes": [ ... ] } ],
  "characters": [ { "id": "...", "name": "...", "age": 23, ... } ]
}
```

Узел сцены (`nodes`):
- `text` — текст; `speaker` — `"me"` (мысли героя), id героини или любое имя; без `speaker` — рассказчик.
- `bg` — фон: `beach`, `cafe`, `night`, `sunset`, `dawn`, `room`, `party`, `storm`, `bus`, или картинка `"assets/имя.jpg"` (файл кладётся в `content/assets/`).
- `char` — какая героиня на экране (портрет берётся из `avatar` персонажа, иначе эмодзи).
- `image` — картинка-иллюстрация сцены поверх фона (`"assets/cg1.jpg"`).
- `choices` — варианты: `{ "text", "next": "<id узла>", "affection": { "lisa": 2 } }`.
- `next` — id следующего узла (по умолчанию — следующий в списке). Последний узел завершает сцену.

Главы идут по порядку файлов (по имени). Возраст персонажа меньше 18 сервер не примет.
