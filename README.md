# Лето у моря: кликер-история для Telegram Mini App

Игра от первого лица: герой приезжает на лето в приморский городок, подрабатывает (кликер), открывает главы сюжета с выборами и общается с тремя героинями. Они отвечают через ИИ и помнят прошлые разговоры. Монетизация через Telegram Stars.

## Что внутри

| Часть | Что делает |
|---|---|
| `web/` | Mini App на React + Vite: вкладки «Работа», «История», «Девушки», «Магазин», читалка сцен, чат, пейвол |
| `server/` | Node + Express + grammY: API игры, бот, оплата Stars, SQLite, ИИ-чат, воронка |
| `content/` | **Весь контент в JSON**: сюжет, героини, экономика, цены. Код трогать не нужно |
| `content/scenes/` | Слот для твоих сцен и глав (см. `content/scenes/README.md`) |
| `content/assets/` | Картинки: фоны, портреты, иллюстрации |

### Воронка
1. Реклама или ссылка `t.me/<бот>?start=<источник>`: источник сохраняется, видно, какой канал окупается.
2. `/start`: приветствие и кнопка «Начать историю», которая открывает Mini App. Кнопка меню бота тоже ведёт в игру.
3. Бесплатно: глава 1, кликер, улучшения, 15 сообщений в день.
4. Главы 2–3 открываются за игровые монеты: игрок втягивается.
5. Пейвол: главы 4+ и часть свиданий входят в «Летний пропуск», сообщения сверх лимита, энергия.
6. Оплата в Stars прямо в приложении (`openInvoice`), выдача покупки строго после `successful_payment`, без дублей.
7. Возврат: игроку раз в сутки приходит напоминание от одной из героинь, если его не было 20+ часов.
8. `/stats` (только для админа): воронка по шагам, выручка, источники. `/refund <id>` возвращает Stars.

### ИИ-героини
- Характер каждой задаётся в `content/characters.json` (поле `persona`).
- Память: последние 20 сообщений, плюс каждые 6 сообщений ИИ выжимает из диалога факты об игроке («его зовут…», «обещал сводить на пирс…») и хранит их всегда.
- Учитывается уровень симпатии из сюжета и подарков.
- Провайдер ИИ подключаемый (`server/src/llm.ts`): по умолчанию Claude, можно добавить свой. Без ключа работает демо-режим с заготовленными ответами.

## Запуск локально (без Telegram)

```bash
npm --prefix server install && npm --prefix web install
npm run build
DEV_MODE=1 npm start         # http://localhost:3000, покупки симулируются
```

## Деплой: что нужно сделать тебе

1. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot` и получить токен. Потом `/newapp`: выбрать бота, указать URL сервера. Получится прямая ссылка `t.me/<бот>/<app>`.
2. **Ключ ИИ.** Создать ключ на [platform.claude.com](https://platform.claude.com) и пополнить баланс.
3. **Хостинг** с HTTPS и постоянным диском (Telegram открывает Mini App только по https):
   - проще всего Railway / Render / Fly.io: «Deploy from repo», они сами соберут `Dockerfile`;
   - подключить volume и смонтировать его в `/app/data` (там база);
   - или любой VPS: `docker build -t game . && docker run -d -p 3000:3000 -v game-data:/app/data --env-file .env game` за nginx/Caddy с сертификатом.
4. **Переменные окружения** по образцу `.env.example`: `BOT_TOKEN`, `WEBAPP_URL` (https-адрес сервера), `USE_WEBHOOK=1`, `WEBHOOK_SECRET`, `ADMIN_IDS` (свой id можно узнать у @userinfobot), `ANTHROPIC_API_KEY`, `SUPPORT_CONTACT`.
5. Перезапустить сервер. Бот сам выставит команды, кнопку меню и вебхук. Написать боту `/start`.
6. **Проверить оплату:** купить самое дешёвое (15 ⭐), затем `/stats` (там видны id последних покупок) и `/refund <id>`, чтобы вернуть Stars.
7. Вывод Stars: через @BotFather → Payments/Fragment, по правилам Telegram (есть холд перед выводом).

## Экономика ИИ: прочитай до запуска рекламы

Модель задаётся в `LLM_MODEL`. По умолчанию стоит `claude-opus-5-5` (лучшее качество): это примерно 1 цент за сообщение. Пак «100 сообщений» за 59 ⭐ приносит около $0.75, то есть на Opus такой пак работает почти в ноль или в минус. Варианты:
- `LLM_MODEL=claude-haiku-5-5`: примерно в 40 раз дешевле, для коротких флирт-реплик обычно достаточно;
- или поднять цены и уменьшить лимиты в `content/products.json` и `content/game.json`.

## Твои сцены и контент

- Новые главы, свидания и героини: JSON-файл в `content/scenes/`, формат описан в `content/scenes/README.md`.
- Картинки кладутся в `content/assets/` и указываются как `"bg": "assets/beach.jpg"`, `"image": "assets/cg1.jpg"`, портрет героини как `"avatar": "assets/lisa.png"`.
- Цены, лимиты, улучшения и подарки меняются в `content/products.json` и `content/game.json`.
- Возраст героини меньше 18 сервер не примет.

## Ограничения Telegram, которые надо учитывать

- Цифровые товары в Mini Apps продаются только за Stars, это уже сделано.
- Правила Telegram для Mini Apps и платежей запрещают откровенный 18+ контент. За такие сцены могут заблокировать бота и вывод Stars. Если нужны откровенные сцены, их обычно выносят на отдельный сайт с проверкой возраста и своим платёжным провайдером, а не в Telegram-версию.
- Бот обязан отвечать на `/terms` и `/paysupport`: это уже есть, подставь свой контакт.
